# Blockers

Updated: 2026-08-26

## Current production blockers

None. The user-approved combined Prism release is promoted and its bounded release gates, artifact identity, launcher, protected-data equality, and immutable rollback parent are verified.

## Explicit verification limits

- Provider-native support remains unverified.
- Generated-output efficacy/adherence, four-way camera-support separability, and repeatability remain unverified.
- The current app is local ad-hoc signed. Developer ID signing, Team ID, notarization, public Gatekeeper readiness, update delivery, and automatic updater rollback are not implemented or verified.

These are limits, not blockers to the verified local canonical production promotion.

## Historical candidate boundary

Earlier rejected or unapproved candidates remain historical/diagnostic only and are not promotion parents. Do not revive v6, v7, old Flight Testers, or unrelated historical candidates as the parent of future work. New software changes start from the current canonical source and preserve the immutable rollback route documented in `docs/release/combined-prism-production-promotion-2026-08-26.md`.
