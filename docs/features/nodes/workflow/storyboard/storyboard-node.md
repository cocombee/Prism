## Current active Storyboard contract — text-only

- A connected Video Generator prompt has independent Locked and User modes. Locked is the live, complete visible Composed Provider Prompt byte-for-byte and remains read-only/copyable. First User entry seeds that exact complete Locked body; later switches preserve User independently while Locked continues to recompile. Explicit Reset alone replaces the entire User body with latest Locked. EDIT CONTROL is compiler-owned and tracks current Video output settings in Locked; User receives those changes only through first seed or Reset.
- Structured Storyboard fields own Seedance TIMELINE/CAMERA compilation. When structured shots exist and authored Video/User prose is empty, never parse the compiled Storyboard carrier prompt as authored prose: each action, quantified camera recipe, and Hard Cut must appear once. Recursive semantic highlighting follows every cycle-safe upstream Character/Wardrobe/Location/Element authority, not only direct edges. Built-in Style instances resolve current preset payload by `stylePresetId`; stale saved prompt bytes never override the current LOOK, while explicitly saved custom Styles remain byte-exact.
- Storyboard is currently a text-only planning surface. It has no active Storyboard Play, Deploy, Rerun, Stop, compiled-sheet generation action, or Storyboard-local image-generation readiness gate. Save, Revamp Shot, Revamp All, Cut, Continue, panel timing, shot size, camera movement, locks, and typed Storyboard output remain active. Video Generator and unrelated node generation controls are unchanged.
- Revamp Shot and Revamp All send a hidden Connected Context Manifest to the selected text provider only after the user clicks Revamp. Model selection alone is free/read-only and never calls Revamp. Clicking Revamp sends a paid AI text inference request to the selected provider and may consume provider credit. Complete structured prompts are preserved byte-for-byte and are filtered before any assistant-provider call.
- Revamp Shot makes one paid assistant request for exactly one editable panel. Revamp All makes one paid assistant request total for one coherent ordered batch, never one request per panel and never a fallback loop. The request carries every panel in original order as full context—stable ID, full prompt, duration, shot size, camera, lock state, normalized Cut/Continue/final boundary, and panel-specific connected context—while only unlocked, non-empty, incomplete panels are editable targets. Locked, empty, and complete structured panels remain byte-for-byte read-only context.
- Provider-semantic tagging is language-agnostic: Revamp Shot and Revamp All receive one hidden policy instructing the selected provider to reason from typed role, safe connected name/caption/weak aliases, panel prose, and full ordered sequence across language, dialect, slang, transliteration, colloquial spelling, and minor misspelling. When exactly one connected authority is semantically unambiguous at point of use, the provider replaces the first natural-language mention with its exact canonical Canvas tag; ambiguity remains untagged. Source validation accepts only exact canonical tags explicitly exposed as connected semantic candidates and still rejects unconnected, wrong-case, duplicate, ordinal, hidden-context, and transport-leaking tags. Language-specific translation dictionaries are not correctness dependencies.
- Revamp Shot mutates only its selected panel but reads every filled earlier and later panel in ordered sequence context before deciding mentions. Both Revamp Shot and Revamp All share one Seedance-aligned mention policy: repeat exact character+wardrobe, Location, and Element anchors at every relevant point of use while avoiding repetitive full descriptions. Adjacent same-scene panels and CONTINUE inherit established description/state; HARD CUT alone does not require reintroducing the same Location. First use, a new Location, re-entry after intervening context, ambiguity, or material state/ownership change may re-establish only what is needed. Empty siblings provide no narrative evidence, and neighbouring prose/introduction ownership never moves.
- Revamp All requires a strict internal ordered JSON response containing exactly one complete prompt for every editable target. Missing, extra, duplicate, reordered, empty, fenced, commentary-bearing, transport-leaking, or individually invalid output rejects the whole batch before any panel mutation. A valid batch applies atomically; failure applies none. The Storyboard status uses only `Storyboard revamped.`, `Storyboard unchanged.`, `Storyboard already complete.`, the existing actionable preflight, or the generic connection failure. Both Revamp controls disable while the scoped Storyboard is busy, with caller-level duplicate-call exclusion and one atomic polite live status lifecycle.
- The manifest is derived only from connected Character, Location, Element/Prop, ordinary Image, Video and Audio Reference authorities. It contains safe semantic metadata only: an existing stable Canvas `@asset-name` anchor when available, typed role, safe display name/caption, and safe aliases. It never contains paths, URLs, credentials, secrets, provider tokens, or raw `@ImageN`/`@VideoN`/`@AudioN` ordinals.
- Typed semantic role is authoritative. Filename/display-name inference remains weak alias evidence and never promotes an ordinary Image into Character, Location, or Element/Prop. The generic Storyboard `reference-in` port reuses the existing typed Image signal and stable Canvas tag contract; it creates no new visible tag family.
- Hinting is resolved independently per authority and alias set. One connected missing Location may require its setting anchor even when unnamed. Separately unambiguous mentioned Element/Image aliases receive structured matched-alias and required-anchor metadata. Before final validation, a surviving exact safe alias is deterministically replaced once with its canonical connected tag; if neither tag nor alias survives, validation rejects the rewrite. Malay/English phone concepts such as `telefon`, `telefon pintar`, `telephone`, `cellphone`, and `phone` remain weak alias evidence only—the typed Element/Image role stays authoritative. Ambiguity suppresses only the competing set, and an authored exact tag suppresses only its own hidden insertion and remains byte-for-byte.
- Provider output validation rejects removal or duplication of authored tags, unconnected or unhinted tags, raw ordinal tokens, hidden-manifest narration, and newly introduced transition/continuity meta commentary. Existing Cut/Continue, SHOT/BEAT/HARD CUT, timing, dialogue, locks, continuity, camera, and smooth-prose rules remain frozen.
- The active Storyboard status stays compact and generic: running shows only `Revamping N panel` or `Revamping N panels` with a CSS-animated one/two/three-dot ellipsis; visible failure is exactly `Could not revamp, check connection.` Detailed non-secret provider/catalog diagnostics remain in Connections. Text-model menus exclude audio/realtime/speech/voice/TTS/transcription/Whisper/sound/music models while retaining text-output vision/multimodal reasoning models. Connected direct-provider model catalogs hydrate when connection state becomes available, without waiting for Connections to open. Until a missing/failed catalog loads, only the valid saved text provider/model is retained as a visible display-name fallback; no other fallback model/provider is invented and the same merged catalog governs selector rendering and Revamp resolution.
- Duration guidance and Storyboard lifecycle status share the `storyboard-feedback-row` component role and the approved control-height centering: `min-height: var(--node-control-height)`, `padding: 0 8px`, flex alignment, `var(--font-node-control)`/400, line-height 1.25. Their specific classes own only semantic surface, divider, and colour differences. One-line rows align optically with the `4 / 4s` budget and Save control; two-line locked conflicts expand naturally without clipping. The panel grid uses native overflow scrolling with wheel propagation isolated from Canvas; it never manually mutates `scrollTop` or cancels native wheel default behavior.
- The active text-only editor uses one ordered, observational sequence budget. New panel choices begin at `1.0s` in `0.5s` increments. The connected generator owns the clip budget; a live native selection is read from its current matching endpoint/fingerprint contract and values, not the legacy model ID. Panel maxima reserve earlier and locked downstream time; unavailable positive choices remain visible, disabled and guarded. Numeric saved timing remains exact on reopen, including values needing review. Legacy Auto is migrated to the existing `1s` default. Invalid saved timing is visible as a disabled review option rather than silently substituted. No panel is clamped, padded, trimmed, stretched or auto-recovered by budget observation. Unknown/automatic/unsupported clip timing has no invented budget. Clip-minimum underflow and overflow produce neutral derived feedback, and generated typed beats below `1s` block before provider preparation. Model clip minima and native per-group constraints remain independent of the beat floor.
- Storyboard panels may additionally persist optional Prism-local typed continuity: continuity group, active and excluded Character tags, authored Character state, sparse state deltas, state-scoped prop/meal authority, and dialogue spans. These fields are additive and load-safe; legacy boundary arrays remain valid. Typed state is authoritative and is never reconstructed from action prose.
- For edited coverage, the compiler inherits complete same-group active-cast state across cuts, applies only explicit deltas, excludes unrelated groups, and emits compact shot-local Character state independently of prose tags. Visibility changes—including blurred, partial, edge, reflected, and off-camera—do not reset position, task, props, contacts, workstation, gaze, or performance. Continuous mode receives no synthetic cut/state boilerplate.
- Revamp Shot and Revamp All receive the same whole-sequence immutable typed manifest. Connected Character context is first scoped to each target panel's active cast, so unrelated groups and explicit exclusions never enter provider input. Returned prose cannot mutate typed fields or drop/change an authored typed value already present in panel prose; Revamp All still requires exact ordered complete targets and validates all output before atomic apply. Locked/Auto, visible Composed Prompt, Storyboard request/autofill, and the provider-neutral semantic body share one canonical master; provider ordinals are translated only in the adapter and completed prompts end with `NEGATIVE PROMPT`.
- Connected visual context exposes exact semantic anchor, typed role, ownership/use, aliases, and sole reference authority only. Captions and metadata appearance descriptions are excluded from the hidden Revamp manifest and may never become provider-visible colour/material/pattern/shape/frame/lens prose. Revamp Shot rejects introduced unapproved appearance attributes before mutation; Revamp All validates every target first and remains atomic. Explicit authored appearance wording remains byte-exact, and an explicit named scoped delta changes only that property.

## Historical imported Storyboard baseline — preserved provenance

- Default to two panels and allow Add Panel up to eight, including odd counts. The node keeps normal node width and scrolls vertically as panels grow.
- Storyboard `Model Target` is planning guidance for the Video Generator model intended later; it is not an image-generation target and does not imply that Storyboard directly renders video. Its grouped options must come from the exact same complete shared catalog as Video Generator—including Text, Image, References, First + Last, and Extend variants—so the two selectors can never drift. The target choice governs model-aware timing, panel guidance, and the Native FPS ceiling used to determine the maximum Motion FPS available for this Storyboard workflow; required media inputs remain the responsibility of the eventual Video Generator. Because choosing a target is non-billable planning, its tooltip always explains this FPS consequence and never substitutes provider-credit, API-permission, entitlement, or submission errors. Keep the selector browsable regardless of account state.
- Each panel has prompt plus inline Shot Size, direct focal length in mm, Duration, and Movement controls. Default them to Wide, unspecified focal length, 1s, and Static. Do not expose Auto Size, Auto Time, Auto Move, or retain hidden Auto behavior in persisted Storyboards. Keep Duration narrow so Movement receives the available row width.
- Keep each panel's circular Revamp action inset at the bottom-right of its `Describe this shot` field, never outside the panel or in the metadata row. Reserve right and bottom textarea padding around that action so prompt text and its caret cannot enter its protected area. Do not expose Detach or a standalone Shot node; individual shots remain panels inside Storyboard or Storyboard Asset data.
- Duration obeys the chosen model's maximum and the storyboard total. Explain model dependence with a tooltip. Every Storyboard Duration label and selected value—both the sequence-limit control and each panel's Duration control—uses the original compact `8px` size and regular `400` weight explicitly, without depending on broader inherited typography. The footer timing-summary text such as `4 / 7s` belongs to this rollback too and must also remain explicitly `8px`/`400`; correcting only the selectors is incomplete.
- Offer comprehensive but understandable camera movement names, grouped with purple section labels and explanatory tooltips. Anchor dropdowns to the select, constrain them to the viewport, and keep their scrollbar visible.
- Support Single Sequence and Separate Shots. Keep labels and selects compact and aligned.
- Storyboard has no image-layout Multi/Single mode. `storyboardMode` remains exclusively Single Sequence versus Separate Shots. Every Storyboard preserves its authored two-to-eight-panel plan and generates one numbered compiled sheet. Legacy mistaken image-layout fields are ignored/removed on load without changing panels, timing, semantic inputs, stale-map state, or compiled media.
- Storyboard exposes no Character-style image aspect-ratio or image-size controls. Its compiled sheet remains one truthful preview of the complete authored panel plan; downstream Video Generator shot planning always receives every authored panel.
- Equalize the Storyboard topbar as one grid rather than intrinsic flex groups. The visible labels are `Model` and `Type`; selector accessibility names and menu options retain the full Model Target and Sequence Type concepts. Model and Type share one label column and exact selector-start edge. The model selector spans every remaining column. On the second row, Type absorbs the true remaining width while the Duration label and compact selector terminate at the same right content edge as Model; when Separate Shots hides Duration, Type spans that released space. Preserve equal control heights. Under the enlarged typography scale, use a compact `44px` Duration track and `4px` column gaps so `Single Sequence` remains readable inside the fixed 315px node without weakening the shared edges. The footer button shows wand + `All`, with `Revamp All` retained as its custom tooltip and accessible name.
- Revamp is prompt enhancement, not generation. Its selector identifies the actual text model with that model company's recognizable logo; fal.ai is the default secure broker route, never presented as though it were the underlying AI model. Group headings use only simple service names such as `fal.ai`, `OpenAI`, or `Google`, never routing qualifiers such as `Via` or `Direct`. Keep the timing summary compact as current total versus limit, such as `2 / 15s`. Storyboard red Play generates exactly one compiled numbered sheet on the same Storyboard node. Merely connecting Storyboard to Video Generator spends nothing and contributes instructions, timing, framing, movement, references, and the current non-stale compiled image only.

## Shot development follow-up — 11 October 2026

Revamp develops sparse panel prose into a shot-specific directed take using the existing Seedance-aligned policy: visible emotional performance, physical action/contact, selected crop/lens/camera and progression within the fixed duration. It preserves the story, references, authored timing and selected metadata; it does not invent new events, cast, costume, setting, lighting/grade/audio defaults or cuts. Both Shot and All receive the same explicit development, permitted-edit and preservation rules. Complete structured prompts remain byte-exact and are excluded before inference.
